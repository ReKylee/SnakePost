# SnakePost

**Team:** Kylee Benisty | Peleg Ben Dor
**Course:** Mobile Game Development, Shenkar

## The game in one sentence

A roguelike twist on Snake: collect parcels to grow, deliver them to matching addresses to shrink, and choose randomized upgrades to survive hazards and bosses, with new loadouts and daily mail sorting between runs.

## How to open and build

1. Open the project in Unity 6 LTS or Unity 6.7.
2. File → Build Profiles → Android → Switch Platform.
3. Build and run on an Android phone.
